# v1.2.1 首轮同行共建 Pilot

本轮只验证三个假设：知识是否改善答案（H1）、同行是否愿意交换真实案例（H2）、人工审核成本是否可持续（H3）。

## 三个窄主题

- `add_wechat`：加微入口与门店承接
- `activity_increment`：活动真实增量
- `repurchase_recall`：复购与召回

## 两周节奏

- 第 1—3 天：内部试填，定向邀请 10 位已认识同行。
- 第 4—10 天：收集案例，优先语音，只做一轮补问。
- 第 7—12 天：人工提炼、脱敏、回传确认。
- 第 10—14 天：交付案例卡，准备本期完整脱敏知识包。
- 样本齐备后：按预注册协议运行 30 题、3 评审离线盲测。

## H2 通过门槛

10 人首轮中：至少 6 人提交、4 份 Qualified、8 条本人确认 Draft；再次参与意愿至少 60%，认为“案例卡 + 完整知识包”匹配投入的参与者至少 70%，且没有授权或回报描述不清引发的投诉。

## H3 通过门槛

Qualified 案例人工总分钟中位数 ≤ 20、P75 ≤ 30、平均补问次数 ≤ 1、每份平均 1—3 条可审原子；案例卡 5 个工作日内交付，每周可稳定处理至少 5 份，隐私、误解或授权返工率 < 10%。

## 当前边界

本期完全人工审核；不接贡献网关、飞书 API 或模型 API，不自动提交、批准、入库或注入 Runtime。未运行完真实试验前，H1/H2/H3 都只能标记为 `Not Evaluated`。
