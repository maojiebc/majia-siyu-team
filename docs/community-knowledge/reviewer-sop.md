# 同行案例人工审核 SOP（Phase 0）

审核顺序固定为：安全 → 是否亲历 → 场景具体 → 判断变化 → 动作明确 → 结果证据 → 成立条件 → 失效边界 → 重复/冲突 → 授权范围。

## 单份处理目标

- Qualified 案例人工总分钟中位数目标 `≤ 20` 分钟，P75 `≤ 30` 分钟。
- 最多一轮补问；一次只问最影响判断的一个问题。
- 每份 Qualified 案例平均形成 1—3 条可审 Draft，不为凑数拆分。
- 案例卡在本人确认后 5 个工作日内交付。

必须分项记录：首次阅读、补问、原子草拟、脱敏、回传确认、最终入库分钟。等待对方回复的自然时间不计人工工时；缺失时间不得当作 0。

## 质量判定

案例质量每项 0—2 分：场景具体、判断变化、行动明确、结果证据、适用边界。

- 8—10 分：优先整理，必要时做一轮补问。
- 6—7 分：直接整理，只保留可审原子。
- 4—5 分：只追问一个最影响判断的问题。
- 0—3 分：归档或驳回，不强行提炼。

`Qualified` 表示可进入原子提炼队列；`Need Info` 表示仅缺一个关键事实；`Rejected` 包括纯观点、无法确认亲历、软文、无法脱敏、撤回或授权不清。

KnowledgeAtomV2 只能由人工从 `Draft → In Review → Approved`。贡献者确认不等于证据升级。客户事实可以覆盖行业默认值，但不能覆盖法律、平台规则和合规红线。

## 停止线

隐私、误解或授权错误导致的返工率达到 `10%` 或出现未处理投诉时，停止扩大征集，先复盘流程。禁止“先自动入库，以后再清理”。
