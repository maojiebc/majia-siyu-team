# 同行案例人工审核 SOP

审核顺序固定为：安全 → 是否亲历 → 场景具体 → 判断变化 → 动作明确 → 结果证据 → 成立条件 → 失效边界 → 重复/冲突 → 授权范围。

案例质量每项 0—2 分：场景具体、判断变化、行动明确、结果证据、适用边界。

- 8—10 分：优先深访，可拆 3—5 条 Draft。
- 6—7 分：直接整理，可拆 1—2 条 Draft。
- 4—5 分：只追问一个最影响判断的问题。
- 0—3 分：归档或驳回，不强行提炼。

审核结论：

- `Qualified`：案例足以进入原子提炼队列。
- `Need Info`：只缺 1—2 个关键事实，一次只追问一个问题。
- `Rejected`：纯观点、无法确认亲历、软文、明显错误、无法脱敏、无新增价值、撤回或授权不清。

KnowledgeAtomV2 必须由人工从 `Draft → In Review → Approved`。贡献者确认只证明提炼没有误解，不等于证据等级自动提高。客户事实可以覆盖行业默认值，但不能覆盖法律、平台规则和合规红线。
