# 同行贡献说明（约 5 分钟）

交一件你亲历、官方文档不会写的事。交完会自动进社区语料；两家不同公司都确认过的，会升成 C 级，不用等维护者。

## 交什么

要具体动作，不要「私域很重要」这种空话。示范类型：

- **平台技巧**：比如企微防骚扰下，把「敏感词」做成「关键字」自动应答。
- **文案钩子**：文案前 5 个字符怎么把人留住。
- **排版**：哪一种排版模式在会话里不容易被截掉。
- **发送时机**：几点发转化更好（请写清业态和班次，不要编造数字）。
- **数字基线**：你店里真实测到的率或人数，带口径和样本量。
- **反例翻车**：按某做法做了，结果更差。
- **厂商体验**：某个工具实际好不好用、坑在哪。
- **规则变化**：平台规则哪一天改了、店里怎么改动作。

公司/品牌必填，入库前会哈希。手机号、门店编号、密钥不要写进「一件有效的事」。

门店数按你真实所在档勾：`1` 单店，`2-10` 老板亲管，`11-50` 要店长层，`51-300` 要区域层，`301-1000` 分公司成型，`1001-5000` 全国多层级，`5000+` 万店级。不要往小里靠。分公司层、你的位置、主要私域载体能填就填，方便别人判断能不能套用。

## 你能拿到什么

管线跑完会回写一张**案例卡**到飞书「回礼」列：判断句、类型、业态/模式/规模、证据等级、同规模带若有数字也会附一行。不用等 5 个工作日。

## 等级怎么定

- 只有你一家说：社区 D 级，会进库，引用时必须写成「单源 D 级」。
- 另一家不同公司也确认：升 C 级。
- 维护者自己交的：A 级。

## 怎么印证别人的一条

飞书表单不能填关联字段。请到「印证」表，把案例卡里的**原子ID**（`ka_` 开头那串）贴进 `印证的原子ID`，并写上你的公司。维护者有空会再把「关联提交」手链上。

表单链接仍用现有飞书入口；字段以 `feishu-base-schema.md` 为准。想撤回自己的提交，告诉发起人即可。
