# 同行贡献者说明

我们需要的不是泛泛观点，而是你亲历的一次判断变化：场景、原判断、真正原因、改前改后、结果证据、成立条件和失效边界。

## 你可以得到什么

- 案例达到 `Qualified` 并由你确认后，5 个工作日内获得一张《同行实战案例卡》。
- 至少一条原子进入 `Approved` 后，获得本期所有有效案例组成的完整脱敏同行知识包，不是只返回你自己的内容。
- 可选署名、花名、匿名、仅内部使用或使用前再次确认。

这是小样本 Pilot，不承诺每份提交都会进入知识库，不承诺对外发布或产生固定收益。案例卡和知识包是本期明确的交换成果。

## 安全与授权

- 不需要填公司或品牌名称。
- 手机号、门店编号、会员或订单明细、密钥和未授权客户资料不要上传。
- 敏感经营数字可以用区间或相对变化表达。
- 原始提交先人工审核，不会直接成为正式知识。
- 你可以在批准前要求修改或撤回。

AI 只协助草拟结构和提示风险，不能自动批准。你的回传确认只证明“整理没有误解你”，不会自动提高证据等级。
