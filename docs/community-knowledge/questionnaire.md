# 《连锁加盟餐饮私域真实案例采集卡》（v1.2.1 Phase 0）

## 开场说明

只收集一件你亲历的事：当时发生了什么、最初怎么判断、后来发现了什么、改了什么、结果如何，以及这条经验在什么情况下不成立。

预计 3—5 分钟。推荐直接录 2—5 分钟语音，也可填文字。不需公司名称；敏感数字可用区间或相对变化。原始内容先脱敏、人工整理，再回传本人确认。

合格案例会在确认后 5 个工作日内获得一张结构化案例卡；至少一条原子经人工审批后，再获得本期完整脱敏同行知识包。这是 Pilot 交换价值，不代表保证录用或对外发布。

## 7 个核心问题

| # | 题目 | 必填 |
|---:|---|---:|
| 1 | 当时发生了什么？请尽量说具体场景。 | 是 |
| 2 | 你最开始认为原因是什么？ | 是 |
| 3 | 后来发现真正原因是什么？ | 是 |
| 4 | 你具体改了什么？改前和改后有何差别？ | 是 |
| 5 | 结果如何确认？可以是数据、现场反馈或重复验证。 | 是 |
| 6 | 这条经验在什么条件下成立，什么情况下不适用？ | 是 |
| 7 | 这是否为本人亲历，并确认内容不含未授权机密、个人隐私或可识别客户信息？ | 是 |

## 轻量元数据

- 当前主题：`add_wechat` / `activity_increment` / `repurchase_recall`
- 贡献者角色：总部 / 区域 / 加盟商 / 店长 / 服务商 / 数据产品
- 业务背景：业务模式、规模和渠道的简短组合
- 授权范围：署名 / 花名 / 匿名 / 仅内部 / 使用前再次确认
- 联系方式：可选，仅补问或使用前确认

附件或语音为可选项。不上传完整聊天记录、会员或订单明细、手机号、门店编号、密钥与未授权客户文件。
