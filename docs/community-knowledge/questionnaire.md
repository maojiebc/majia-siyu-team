# 《连锁加盟餐饮私域真实案例采集卡》

## 开场说明

这不是行业观点调查。我们只收集一件你真正经历过的事：当时发生了什么、你原本怎么判断、后来发现了什么、采取了什么动作、结果如何，以及这条经验在什么情况下不成立。

填写约 3—5 分钟。不需要提供公司名称，敏感数字可以填区间，也可以上传语音、截图或脱敏复盘。原始内容不会直接公开；先脱敏和结构化，再回传给你确认。只有经你明确授权的内容，才可能进入同行经验库和后续 AI 工具。

## 题目与字段映射

问卷直接同步到 `问卷提交（自动同步）`，通过人工初审后再转入 `原始案例`，从而隔离填写人可见字段与内部审核字段。
