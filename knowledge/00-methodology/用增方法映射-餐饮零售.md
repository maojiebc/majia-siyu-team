## 先说清楚：这页干嘛用

- **问诊 / 诊断**：先用文末「九项体检」，找到卡在哪一节，再给方案。  
- **写群发 / 朋友圈 / 话术**：方案上必须挂「给谁、图啥结果、怎么算数」，禁止只交差一堆文案。  
- **后台自动跑**：这页是方法说明书；正式进检索的「一条条干货」仍要人工审过（现在还不自动灌进后台）。

## 默认前提（加盟店也适用）

- 生意：加盟连锁餐饮为主，多店 / 单店零售也能套。  
- 通道：企业微信好友、群、朋友圈、店里、外卖袋子、团购。  
- 死规矩：
  - 别假设总部能逼加盟店照做；
  - 给人打标签得跟**真实消费**挂钩，企业微信里随手点的标签没用；
  - 合规先过：不许诱导分享、不许绝对化承诺、不许偷偷要隐私；
  - **先把怎么算说清楚，再谈上系统**；算口径/SQL 去 majia-huiyuan。

## 数字怎么说（禁止混用）

每个「率」都要写死三样：**分子 / 分母 / 看多久**。  
「一共多少人」是累计；「活不活、买不买」是一段时间里的数。

| 词 | 人话定义 | 常见装傻 |
|---|---|---|
| 有效加微 | 真加上了，还没马上删/拉黑（可看 24 小时） | 把扫码次数当加人 |
| 加微率 | 有效加微 ÷ 看到码/进店的人 ÷ 同一时段 | 分母拿「历史总会员」 |
| 入群率 | 进群 ÷ 有效加微 ÷ 观察几天 | 群人数当好友数 |
| 首单转化 | 加上后 T 天内有消费 ÷ 有效加微 | 领券当买单 |
| 复购率 | 窗内买 ≥2 次的人 ÷ 有消费的人 | 跨天算法没说清楚 |
| 活跃 | 这段时间有互动 **或** 有消费（二选一，项目启动时写死） | 跟「还在不在池子里」搅一起 |
| 沉默 | 超 N 天没消费也没正经互动（N 按这品类多久该来一次） | 全国一刀切 30 天 |
| 拉客成本（也叫 CAC） | （礼+券+摊到人头的人力+物料）÷ 有效加微或有效首单 | 只算券面额 |
| 长期贡献（也叫 LTV） | 观察窗里一个客人贡献多少（先定算流水还是毛利） | 拿「转化涨了几个点」冒充 |
| 戳人成本 | 发消息带来的烦（退群/屏蔽）+ 人力 | 觉得群发不要钱 |

**品类节奏**：快餐/饮品来得勤，正餐/火锅慢一点，零售看囤货。沉默几天算「该喊了」，必须按品类调，别抄 App 的「7 日活跃」。

## 挂在私域五步上

| 五步（人话） | 阶段 | 这页重点 |
|---|---|---|
| 立住人设 → 把人加进来 | 刚起步 | 先定值得拉谁、加微三步、哪条渠划算 |
| 群热起来 → 分清生熟客 | 要做大 | 分群、找掉人最多的一截、活跃/沉默分开 |
| 勾回头客 → 能复制 | 已经熟了 | 预警召回、主打款、节点获客（合规）、长期贡献 |

## 16 条能干货（主句）

1. **拉新先锁「值得拉的人」**，再选渠道和钩子——别一上来就砸券。  
2. **渠道用「拉客成本 × 一段时间贡献」拍板**，集中打穿最好的 1～2 条触点。  
3. **加微必拆三步：看到了 / 扫了 / 加上了**，禁止只盯「今天加了几个」。  
4. **转化：先画整条路找断点 → 一次只改一样小流量试 → 再全开**，禁止同时改一堆。  
5. **池里活跃 / 池里沉默 / 外面吃过同类的 / 外面从没吃过的** 四拨人分开玩，禁止全员同一条群发。  
6. **沉默按品类「该来的周期」提前预警**，由浅到深戳人；禁止盘死了再全员轰炸。  
7. **群里出单 = 从哪来打标 × 按身份分群 × 价格/促销小试验**，统一群发抬不起核销。  
8. **提业绩看三面：自己历史、平台流量、外面趋势**，再定主打款和预算。  
9. **活动款走四段：筹备 / 启动 / 放量 / 收成**；收成期收回补贴，转成会员常规权益。  
10. **蹭节点要切时间窗**，用「立刻能到店用的东西」接住；带人来必须合规。  
11. **「还在池子里」≠「还会来」**，指标和手段分开。  
12. **分层必须绑真实消费**，分档阈值按品类校准；企业微信空手打标签不够。  
13. **店员高峰多出来的动作是一等约束**；设计成「一句话 + 一指码」。  
14. **反面教材：拿累计会员数当核心成绩**（累计只配附录）。  
15. **反面教材：只交群发文案、不挂「给谁、图啥、怎么算」**。  
16. **增长体检九项缺一，先补定义再给方案**（见下）。

## 增长体检九项

1. 目标 / 高贡献客人长什么样，写清楚了吗？  
2. 各触点有没有分步计数和拉客成本？  
3. 看到 → 扫码 → 加上，哪一跳最差？  
4. 加好友 → 欢迎语 → 进群，串起来了吗？  
5. 加上后 T 天首单率？卡在领券还是到店？  
6. 按来源 / 身份分群做了吗？  
7. 沉默几天算该喊，按品类定了吗？有升级路径吗？  
8. 现在主打活动卡在四段里的哪一段？  
9. 还能戳到的人数、退群率在看吗？

## 挂到哪些本事上

| 主句 | 优先用的本事 |
|---|---|
| 1–4, 8–9, 13, 15 | 运营当投放看、转化口径、轻问诊 |
| 5–6, 11 | 沉默唤醒、转化口径 |
| 7, 15 | 群发、内容当产品、话术 |
| 10 | 内容当产品、合规红线、朋友圈 |
| 12, 14, 16 | 轻问诊、转化口径（算细账 → majia-huiyuan） |
| 8 涉及外面事实 | 先做市场调研留证 |

## 明确不做

- 不把 App 的「日活/次留」当餐饮主指标。  
- 不把没核对的第三方案例百分比当行业标杆。  
- 不设计诱导分享、假倒计时、绝对化承诺。  
- 公开层不写真实客户做法、券面、门店编号。
