# 用增方法映射 · 餐饮零售（公开方法层）

> 定位：连锁加盟餐饮 / 门店零售的**用户增长 Know-how**公开映射。  
> 不是客户专属 SOP，不含真实阈值、券面与门店数据。  
> 与 `私域公理与消解案例库.md`、`02-industry/catering/` 配套；会员口径/SQL 仍归 [majia-huiyuan](https://github.com/maojiebc/majia-huiyuan)。  
> 版本：随仓库 `VERSION` 发布；v1.2.4 首发；v1.2.5 全渠道对齐。

## 使用方式

- **问诊 / 诊断**：先用文末九项体检，定位断点，再给方案。  
- **执行技能**：群发、朋友圈、话术方案须挂载对应指标与分群，禁止只交文案。  
- **Runtime**：本文件是方法真源之一；正式 Atom 检索仍以审核通过的 JSONL 为准（v1.2.5 仍不自动注入 Runtime）。

## 行业默认前提

- 业务：加盟连锁餐饮为主，多店/单店零售可复用。  
- 渠道：企微好友 / 社群 / 朋友圈 / 到店 / 外卖包材 / 团购。  
- 约束：不假设总部能强制门店执行；标签须能挂消费行为；合规前置。  
- 阶段：`cold` 冷启动 · `growth` 扩张 · `mature` 成熟（见 `catering/stages.md`）。

## 指标字典（分子 / 分母 / 时间窗必须写死）

| 指标 | 默认定义 | 常见错用 |
|---|---|---|
| 有效加微 | 通过好友且短期未删/拉黑 | 扫码次数当加微 |
| 加微率 | 有效加微 ÷ 触点曝光或进店人次 ÷ 同周期 | 分母用累计会员 |
| 入群率 | 入群 ÷ 有效加微 ÷ 观察窗 | 群人数当好友数 |
| 首单转化 | 加微后 T 日内有消费 ÷ 有效加微 | 领券当首单 |
| 复购率 | 窗内 ≥2 次消费会员 ÷ 有消费会员 | 未声明跨天口径 |
| 活跃 | 窗内互动 **或** 消费（启动时写死一种） | 与留存混谈 |
| 沉默 | 超 N 日无消费且无有效互动（N 随品类复购周期） | 全国统一 30 天 |
| CAC | （礼品+券+可归属人力+物料）÷ 有效加微或有效首单 | 只算券面 |
| LTV | 观察窗内单客贡献（先定毛利/实收口径） | 用转化提升幅度冒充 |
| 触达成本 | 触达规模带来的疲劳（退群/屏蔽）+ 人力 | 以为群发免费 |

## 与私域五步的挂接

| 五步 | 阶段 | 增长层重点 |
|---|---|---|
| 造 IP → 做链接 | cold | 画像、加微三跳、渠道 CAC |
| 促活 → 分层 | growth | 分群、漏斗断点、活跃/沉默定义 |
| 复购 → 规模化 | mature | 预警召回、主爆结构、合规节点获客 |

## Know-how 主句（16）

1. **拉新先锁高贡献顾客画像**，再选渠道与钩子。  
2. **渠道用 CAC × 观察窗价值决策**，集中打穿最优 1–2 条触点。  
3. **加微必拆曝光 / 扫码 / 通过**三跳，禁止只盯新增总数。  
4. **转化：漏斗找断点 → 单变量小流量验证 → 全量**，禁止同时改一堆东西。  
5. **池内活跃 / 池内沉默 / 池外品类存量 / 池外增量**策略拆开，禁止全员同一张群发。  
6. **沉默按品类复购周期预警触发**，触达深度升级；禁止盘死了再全员轰炸。  
7. **社群转化 = 来源打标 × 身份分群 × 促销实验**，统一群发无法稳定抬核销。  
8. **提业绩看三视角：自己结构、平台流量、市场趋势**，再定主爆与预算。  
9. **活动品走筹备 / 启动 / 爆发 / 成熟**；成熟期收回补贴、转常规权益。  
10. **借节点获客要切时间窗口**，用可到店的结果物承接；裂变必须合规。  
11. **留存（还在可触达池）≠ 活跃（还会来）**，指标与策略分开。  
12. **RFM/分层必须绑定真实消费**，分档阈值随品类校准；企微手工标签不够。  
13. **店员高峰额外动作成本是一等约束**；设计「一句话 + 一指码」级最小动作。  
14. **反模式：用累计会员数当核心增长 KPI**（只作盘面附录）。  
15. **反模式：只交群发文案、不挂用增口径**。  
16. **增长体检九项缺一则先补定义再给方案**（见下）。

## 增长体检九项

1. 目标/高贡献画像是否写清？  
2. 各触点是否有分步计数与 CAC？  
3. 曝光→扫码→通过哪一跳最差？  
4. 加好友→欢迎语→入群是否闭环？  
5. 加微后 T 日首单率？断在领券还是到店？  
6. 来源/身份是否分群运营？  
7. 沉默阈值是否按品类设定并有升级路径？  
8. 当前主推活动处于四阶段哪一段？  
9. 净可触达与退群率是否在看？
