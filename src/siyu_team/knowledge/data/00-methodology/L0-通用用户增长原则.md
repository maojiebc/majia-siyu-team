# L0 · 通用用户增长原则

> **层定位**：跨行业、跨渠道的增长判断骨架。  
> **不写**：企微/门店/加盟/品类券面等场景壳。  
> **说人话**：术语首次出现带白话；读者不用查字典。  
> **来源**：大宁「是大宁啊/我是大宁」Get 笔记原始口播中的**方法骨架**（非面试包装术、非教学假数字）；并吸收可跨行业成立的关系/触达公理。  
> **用法**：任何业态先用 L0 定结构；落到具体生意再叠对应 L1。

---

## 0. 原始语料里「能上升为通用」的东西是什么

大宁语料主体是**用户运营/用户增长面试问答**。去掉「怎么包装履历」之后，反复出现且**不依赖 App 或餐饮**的结构是：

| 原始表达（口播大意） | 上升后的通用原则 |
|---|---|
| 高效拉新五大步骤：画像→核心价值→渠道清单测试→用获客成本与用户价值选优→集中资源 | 先人后渠，先试验后放量 |
| 高价值用户=高客单+高频；先挖再扩 | 增长从已证明会付钱的人出发 |
| 站内活跃/休眠 × 站外存量/增量，分策 | 池内池外、热的冷的，不能同一套动作 |
| 流失预警→自动触发召回；补贴要算投入产出 | 召回是系统，不是心情群发 |
| 漏斗找流失点→针对性策略→AB→全量 | 断点实验，禁止同时改一堆 |
| 来源打标→分群→内容/货/促销匹配→实验 | 分群运营先于文案优化 |
| 看自己/看平台/看市场再定主爆 | 业绩诊断三角 |
| 爆品筹备→启动→爆发→成熟 | 供给也有生命周期 |
| 热点拆窗口，结果可分享、关键信息可解锁 | 节点增长靠窗口与结果物 |
| 留存 vs 活跃要分清；生命周期/RFM 要有数与策略 | 定义分清，分层有数 |
| 累计大数不等于经营质量（题库隐含 + 行业常识） | 累计用户数不是核心成绩 |

**明确不进 L0**：面试自我介绍 AIDA、履历包装、「把发朋友圈包装成项目」的话术技巧。

## 1. 增长在干什么（第一性）

用户增长不是「多搞点活动」，而是持续做三件事：

1. **找到并拉对的人进来**（值得服务、能付钱、可能再来）  
2. **让他们完成关键行为**（首次购买/使用，而不是只留下账号）  
3. **让对的人更常来、花更多、或带人来**——在**可接受的成本**内  

任一环节缺定义（谁算对的人、什么叫完成、成本怎么算），后面的策略都是热闹。

## 2. L0 原则原子（从原始方法骨架抽出）

### L0-01 先锁「值得拉的人」，再谈渠道

- **判断**：拉新的第一步是定义高价值用户长什么样，不是先选投放或活动形式。  
- **原始依据**：拉新五步之①「分析现有高价值用户画像，明确精准拉新群体」。  
- **怎么干**：用已有成交/行为数据回答：谁客单高、谁来得勤、谁爱带人；一句话写清目标人群。  
- **失效**：画像拍脑袋；或把「所有能加上的人」当目标。

### L0-02 先说清「你对他的不可替代价值」，再设计钩子

- **判断**：策略必须对准目标用户的刚需与你能稳定交付的核心价值，而不是对准你想推的活动日历。  
- **原始依据**：拉新五步之②「调研+数据，明确平台之于目标用户的核心价值，再策划策略」。  
- **怎么干**：写清：他为什么非你不可（省时间/更便宜/更稳/更好玩…）；钩子只是价值的入场券。  
- **失效**：价值说不清，只能靠更大额补贴硬拉。

### L0-03 渠道先清单试验，再用账选优，最后集中火力

- **判断**：公域/私域所有可试渠道先并列、按序小测；用「拉来一个有效用户花多少钱」和「他一段时间贡献多少」选优；然后把资源压到最优 1～2 条。  
- **原始依据**：拉新五步之③④⑤；题库追问拉客成本/一段时间贡献/投入产出口径（也叫 CAC/LTV/ROI）。  
- **人话指标**：  
  - 拉客成本 ≈ 为获得一个**有效用户**花的总代价  
  - 一段时间贡献 ≈ 观察窗内平均一个人带来的价值（先定算流水还是利润）  
- **失效**：平均使力；或只看新增人数不看成本和质量。

### L0-04 有效用户必须先定义，再谈新增量

- **判断**：没有「什么叫有效用户」，新增数字不可比、策略不可迭代。  
- **原始依据**：题库逼问获客成本、有效用户、生命周期价值计算口径。  
- **怎么干**：项目启动写死：有效=注册？首单？留存次日？加好友且未秒删？  
- **失效**：今天用注册、明天用首单，还在同比环比。

### L0-05 池内/池外、热的/冷的，策略必须拆开

- **判断**：站内活跃、站内休眠、站外已用过同类的、站外从未用过的——目标不同，动作不能共用一套。  
- **原始依据**：高 ROI 增长四步中的站内活跃/休眠、站外存量/增量分策。  
- **怎么干**：至少四格策略表；禁止「全员同一条群发/同一张券」。  
- **失效**：用召回券去砸从未接触过你的人，或用拉新钩子去烦老客。

### L0-06 召回靠预警机制，不靠运动式群发

- **判断**：休眠用户应在越过「该回来的周期」时进入队列，由浅到深触达；补贴召回必须算投入产出。  
- **原始依据**：流失预警自动触发召回；题库追问触达率/召回率/补贴 ROI；留存方法论=分生命周期差异策略。  
- **怎么干**：定义沉默阈值→自动进队→轻触达/利益/少数一对一升级→看退出力（退订/卸载/拉黑）。  
- **失效**：盘死了才「全员召回大促」。

### L0-07 留存和活跃是两件事

- **判断**：「人还在不在可经营池里」和「人会不会深度使用/消费」必须分定义、分策略、分指标。  
- **原始依据**：题库原话级要求「流程(留存)和活跃有什么区别」「分别如何提升」。  
- **怎么干**：两套数并排看；提升活跃不靠无限加密触达。  
- **失效**：用日更刷屏次数当活跃 KPI，池子被刷薄。

### L0-08 转化：先画路径找断点，再单变量试验，再放大

- **判断**：科学提升转化=梳理用户转化路径→定位关键流失点→针对策略→小流量对比试验→全量应用最优解。  
- **原始依据**：面试官纠偏「科学化提升转化率」四步；产品侧灰度/归因思路。  
- **怎么干**：一次只改一个主变量；说不清对照，就还没资格全量。  
- **失效**：同时改价格、文案、入口、人群，结束只剩故事。

### L0-09 分群先于内容：来源打标 × 身份分群 × 匹配 × 实验

- **判断**：转化差时优先分群，而不是先重写文案。来源不同、身份阶段不同，内容/货/促销都该不同，并用试验找组合。  
- **原始依据**：社群转化满分答（来源分析→分群→匹配→价格促销 AB）。  
- **怎么干**：来源字段必有；至少按生命周期或身份切 3 群；群内再 AB。  
- **失效**：建了很多群，发的却是同一条复制。

### L0-10 业绩诊断要三角：自己、场、大势

- **判断**：提流水（GMV）/收入前，同步看自身历史结构、所在平台/场域的流量结构、外部趋势，再定主推与预算。  
- **原始依据**：商家流水「看自己、看平台、看市场」。  
- **怎么干**：三页便签再开会：自家贡献结构 / 场上什么在吃流量 / 外面什么在变。  
- **失效**：只听感觉定主爆，或只抄竞品皮。

### L0-11 供给与活动也有生命周期

- **判断**：新品/爆品经历筹备→启动→放量→成熟；成熟期目标从放量转为利润、忠诚与防御，而不是永远补贴。  
- **原始依据**：打爆新品四阶段。  
- **怎么干**：每阶段写清主目标、主动作、退出条件。  
- **失效**：筹备不足直接全网放量；或放量后没有退出补贴的机制。

### L0-12 借势要切时间窗，并用「立刻有用的结果」接住

- **判断**：大热点要拆成需求不同的子窗口；承接物应即时反馈、可传播，关键信息可设计进阶，而不是一句「快来」。  
- **原始依据**：高考热点案例（考前/中/后窗口 + 可生成报告 + 解锁式传播）。  
- **怎么干**：先写窗口表（何时/谁痛/给什么结果物/如何合规传播）。  
- **失效**：整段热点只发打折话术；或诱导式强迫分享（合规红线，见 L1/合规包）。

### L0-13 分层必须有数：生命周期或消费深浅，都要落到定义与策略

- **判断**：说分层却说不出各层定义、各层重点动作，等于没分层。  
- **原始依据**：题库强追生命周期分层重点、「多久没来/来得勤不勤/花得多不多」（RFM）数值与分层策略、重点运营哪层。  
- **怎么干**：选一种主分层（生命周期 **或** 近度/频次/金额），写：定义、人数、主策略、主指标。  
- **失效**：标签很多，但和下单/行为对不上。

### L0-14 增长是实验闭环：假设→动作→指标→复盘→迭代

- **判断**：没有「用数据改策略」的闭环，只算活动执行，不算增长。  
- **原始依据**：多处要求「讲一个通过数据分析迭代运营策略的成功案例」；高 ROI 四步之实验验证。  
- **怎么干**：每个动作写假设与成功线；复盘只保留可复用结论。  
- **失效**：周周有活动，月月无可沉淀方法。

### L0-15 预算变紧时，先保效率，不先保声量

- **判断**：缩预算时，优先保留「单位成本最优 + 用户质量最优」的渠道与人群，而不是按比例砍一切。  
- **原始依据**：题库「突然缩减预算如何最大化拉新效果」；小公司高 ROI 叙事。  
- **怎么干**：按拉客成本×质量排序砍到只剩头部渠道；用实验而不是用感觉加回。  
- **失效**：先砍算得清的、留着面子项目。

### L0-16 累计用户规模不是核心经营成绩

- **判断**：累计注册/累计粉丝/累计会员只能当附录；核心看一段时间里的有效新增质量、关键行为完成、重复消费与可经营池健康。  
- **原始依据**：题库全链路都在逼「质量与口径」而非累计大数；行业上「有会员≠会运营」同构。  
- **怎么干**：看板默认周期指标；累计折叠。  
- **失效**：年底冲刺「破 X 万用户」运动式灌水。

## 3. L0 能力地图（来自原始题库结构，去面试壳）

把通关题库当成**能力清单**，而不是考题：

| 模块 | 你必须能说清 |
|---|---|
| 拉新 | 人群、价值、渠道试验、拉客成本、放量 |
| 裂变 | 机制、每个老客带几个新客、补贴账、合规 |
| 定义 | 留存 vs 活跃 |
| 留存/活跃 | 分策略、分指标 |
| 召回 | 预警、队列、深度、效率 |
| 分层 | 生命周期或消费深浅，有数有策 |
| 转化 | 路径、断点、首单 |
| 再买 | 第一次再买、第二次再买、频次 |
| 价值 | 一段时间贡献、会员/成长体系关键点 |
| 闭环 | 一次完整的数据改策略故事 |

## 4. L0 不回答的问题（必须下沉 L1）

- 用企业微信还是个人微信、码怎么铺、店员高峰怎么说  
- 品类多久算沉默、堂食外卖怎么拆  
- 平台隐藏套餐、团购评分、加盟管控  
- 具体合规话术与红线细则  
- 真实券面、阈值、话术（L2 客户私有）

## 6. 语料边界（诚实声明）

- 大宁语料是**口播 ASR**，数字多为教学示范，L0 **不继承任何具体百分比/绝对量**当 benchmark。  
- L0 只继承**可迁移结构**。  
- 面试包装内容已剔除，不进入原则库。
