# 经营画像与执行边界

公开包只有一套增长方法。行业、直营/加盟、门店规模不是另写 N 套打法，而是两个修饰维：经营模式改「谁能强制执行」，规模改「谁来干、能不能靠个人」。

## 经营画像五问

动手前先对齐这五项。已有答案就用，不要重问。

1. **行业及子类**：餐饮·正餐 / 餐饮·快餐小吃 / 餐饮·火锅烧烤 / 咖啡茶饮 / 烘焙甜品 / 零售·便利店 / 零售·商超生鲜 / 零售·服饰美妆 / 零售·母婴宠物 / 其他。
2. **直营 / 加盟 / 混合**：总部能不能管到店里的人。
3. **门店数**：落在哪一档——`1` / `2-10` / `11-50` / `51-300` / `301-1000` / `1001-5000` / `5000+`。
4. **有无分公司或区域层**：有没有一层人夹在总部和门店之间。
5. **私域主载体**：企微、个微、微信社群、小程序会员、公众号、抖音快手私信、小红书，以哪一个为主。

## 经营模式怎么改输出

- **直营**：可以写进考核、班次、强制 SOP。动作要有负责人、检查方式和完不成的后果。
- **加盟**：总部不能假定店会照做。只给工具、模板、话术和激励；每条建议标明执行边界（总部只能供工具与激励 / 店主自决）。不要写「全网统一执行」。
- **混合**：直营店和加盟店分开给，不要揉成一套。

## 门店规模怎么改输出

- **1**：单店。老板就是店，个人号和当面交代就能转起来。
- **2-10**：老板亲管。个人 IP、店长朋友圈、老板在群里说话，可以当主力。
- **11-50**：需店长层与 SOP。老板盯不过来，要可抽检的步骤和统一物料位，少靠个人发挥。
- **51-300**：需区域层，个人 IP 不可复制。复制的是步骤、检查表和激励，不是某个人的号。
- **301-1000**：分公司/大区体系成型。先问谁在分公司拍板，再写动作。
- **1001-5000**：全国多层级，加盟商群体是执行主体。总部只供工具、模板和激励。
- **5000+**：万店级。标准化与分公司间执行差异是核心问题。先定边界，再谈玩法。

没有区域层时，不要设计「区域经理周会」这类动作。

## 零售和餐饮的私域载体

- **餐饮**：钩子常常落到到店、核销、堂食/外卖袋上的码。
- **零售**：不要默认「到店吃饭」。更常见的是导购个微、小程序会员、O2O 复购、到柜或到店自提。钩子要对着导购能做完的那一步，而不是餐厅那套口播加微。

## 谁来收集、存在哪

- **单步文案**（朋友圈 / 群发 / 话术）：从对话和已有档案推断画像。缺了关键项，最多再问一个；不要开五问问卷。
- **问诊 / 整盘诊断**（问诊、全盘诊断）：Step 0 收齐五问，再出方案。
- **存档**：`siyu-save` 把这五项写入客户档案的「经营画像」；下次 `siyu-restore` 先读回来，不让用户重讲。
