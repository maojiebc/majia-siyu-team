# 分渠道文案与触达节奏

适用于朋友圈、1V1、门店群、欢迎语和配套评论。2026-10-19 从已存档的跨行业沟通样本与既有研究判断中审阅提炼，作为生成与审稿方法采用；没有点击、订单、完整送达或对照实验，不能称为高转化模板。原始文案、图片、身份与来源映射不随包分发。

## 先定任务，再选写法

先用当前简报确认：读者现在想完成什么、与账号是什么关系、这条内容希望带来什么、哪些事实可用、谁能接住回应。缺的是关键业务事实才问；已知信息足够时直接出稿。缺价格、库存、配料、活动资格或入口时不从旧案例补齐；有待填项的稿标为待核稿，不说可直接发布。

| 读者任务 | 组织方式 | 配图承担的工作 | 不适用时怎么改 |
|---|---|---|---|
| 临近消费，想知道吃什么、用什么 | 具体场景 → 商品如何满足 → 可执行下一步 | 场景与商品识别 | 没有真实场景素材就用产品展示，不编亲历故事 |
| 在几项里选择 | 先说比较维度，再列选项与差异 | 对齐同一维度、规格和单位 | 互补商品不能排成只能选一项 |
| 搭配一套、安排一餐或完成一个过程 | 先整体结果，再拆部件或阶段 | 整体加细节、流程或时序 | 不强行压成三项，也不让多个入口争抢注意 |
| 看自己能否享受权益 | 资格 → 权益单位 → 获得及使用条件 → 入口 | 每组资格贴近对应权益 | 等级、门槛或叠加规则未知就不做领取承诺 |
| 使用教学、服务或售后 | 直接回答 → 必要步骤 → 需要时的求助入口 | 步骤与识别点 | 不在服务答案里强塞销售 |
| 品牌记忆、审美或生活灵感 | 一个主题 → 可观察的细节 | 气氛、产品特征或整体感受 | 可以没有购买动作，不编顾客见证来凑结构 |

行业提供检查重点，不能替代具体任务判断：餐饮/饮品关注餐段、规格、口味与到店条件；生鲜关注数量单位、储存和做法、履约范围；服饰关注搭配、尺码和真实上身资料；美妆关注规格、适配依据与功效证据；旅游关注日期、出发地、预约与退改对象。不要把低频品类写成每日催购，也不要把美妆类型标签当个体诊断。

从中选一两种适用结构即可，不必向用户交完整分析表。好文案首先帮读者理解和行动，不靠固定 emoji 数量、标签、痛点或见证。符号可作目录和分组，也可以完全不用。视觉风格服从本次品牌与用户要求。

## 渠道改变信息任务

| 场景 | 首先完成的事 | 通常的写法与承接 |
|---|---|---|
| 朋友圈 | 让刷到的人认出与自己的关系 | 场景、价值或观点先行；正文、图片、评论分工，不默认全是促销 |
| 有真实提问的1V1 | 回答对方这次的问题 | 先答已知部分，未知部分说清核实对象，再给必要下一步；不先群发一段广告 |
| 没有互动上下文的1V1 | 清楚表达一次单向触达 | 说明身份及本次信息；不能说“知道你喜欢”“上次买过”“专门留给你” |
| 门店群 | 让本群顾客知道本店能做什么 | 可参与人群、本店条件、动作与承接；总部素材需门店确认库存、价格、营业和接单能力 |
| 兴趣或服务社群 | 提供共同价值、规则或支持 | 不假设有实体店，不默认到店核销；通知也不必伪装成私人聊天 |
| 新好友欢迎 | 认领身份，兑现添加动机 | 扫码为查资料先给资料，为咨询先答问题，为领礼先讲领取及条件；长期关系理由可随后给 |
| 进群欢迎 | 说明群能帮什么、如何使用 | 重要群规则与求助方式，已有承诺先兑现；不把新人进群当成同意不断促销 |

欢迎语是关系阶段，1V1是渠道，两者不能互相替代。材料里的首条缓存、自动语气或“新人”字样不能证明欢迎触发；需要关系开始的记录或明确的人工作证。欢迎也可能由文字加卡片组成，检查实际顺序与“上方/下方”的指向。

同一活动先共用一张事实表：对象、商品/规格、权益单位、资格、领取与使用条件、期限、地域/门店、入口和履约负责人。再按渠道补足所需信息。内容完全相同在某些通知中成立，不为显示差异而改写事实；没有独立渠道实测不能宣布某版更有效。

## 正文、图片、卡片和评论分工

正文先交代与读者的关系，图片帮助识别、比较或理解，卡片提供实际入口，作者补充评论可承担相关商品、使用提醒、门店路线或后来新增的信息。一个组合里的多条消息不自动等于多次独立营销；卡片通用描述也不自动等于运营当次写的正文。

关键资格、价格单位、不可用日期、门店限制等必须在做决定的位置可见，不能为保持正文清爽而仅藏在评论。已知的重要限制随初次发布出现；活动页也要同步。后续规则变更需按实际可修改方式更正主内容及承接页，必要时撤停，不靠补评维持过期承诺。

补评论前先检查四件事：对应哪条动态、是否作者本人、是否在回复某人、具体新增什么。作者自评不是顾客口碑。回复目标没保存就不补造对话；评论字段缺失不等于没人评论。观察到的间隔只能描述发送行为，不能据此给出“几分钟后补评增加曝光”的规则。没有新信息可以不补评。

## 发布时间、更新与触达频次

把四类时间分开：源内容发布时间、评论时间、活动有效期、素材采集/文件更新时间。文件今天更新不代表正文今天发布；归档时间不用于推断最佳发送时间。统一时区后才比较，缺时区标未知；旧素材可借结构，权益和链接不继承。

排期由消费决策、兑现期限和接待能力倒推：餐前提醒要赶在顾客决定前；预约内容留出预约期；补货跟实际消耗和需求；售后跟服务节点。没有响应数据时给少量可执行的待试窗口并写理由，不承诺行业黄金时段。无需为每条稿强排精确到分钟的发送点。

合看朋友圈、群和私聊，分清“正文+卡片”的一次组合、必要更新和无新增信息的重复提醒。品类消费频次不等于同品牌复购频次；挑战活动规定的消费次数不等于自然消费周期。固定时刻和高条数都不能证明机器人、灰产或低质量。

后续只在有可用数据时评价：同类人群、渠道、活动与时间窗内看真实回复、咨询、核销以及拒收；有可靠送达分母才计算对应转化率，没有打开记录不算打开率。阅读更清楚、模型遵循规则、经营结果变好是三种不同证据。

## 一个合成示例：同样上新，先解决不同问题

前提：社区烘焙店新品可到店购买、售罄即止，无折扣；扫码承诺提供配料表，现未收到核实版。以下为待填示例，不使用真实品牌或活动。

欢迎：“你好，我是【门店】的店员。你扫码想看的【产品】配料表，我核对后发你。”配料核实前不承诺不含某种过敏原，也不先推入群。若资料已备齐，就直接发送，不机械保留“稍后”。

门店群：“【产品】上新了，可到店购买，售罄即止。想先了解配料的，可以在群里问我。”发布前确认本店仍有货、有人能答，别把“欢迎问”变成无人承接的口号。

朋友圈可以从真实食用场景或产品特征组织；已知事实只有“新品”时先给简洁上新稿，不能凭行业补造“现烤、低糖、无添加”。图片是否需要价格、配料或步骤取决于本次任务，见 [文图协作与生图简报](文图协作与生图简报.md)。
