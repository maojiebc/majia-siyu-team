# 2026-10-21 第四轮：咨询回答精简排版、文案默认带 emoji

## 改了什么（相对已提交的 `63e6e3b`）

按马甲本人第三轮盲评时说的偏好改：

- **咨询回答**：老板没耐心看长文。第一行加粗写结论，再分两三块，每块一个加粗小标题、下面一行一条；概念用一句大白话加一个例子讲。入口、问诊和选型都加了这条；选型把来源链接放在后面，方便老板自己核对。
- **文案**：朋友圈和群消息默认带 emoji。首句一个和内容对得上的，时间、地点、价格、条件各占一行、用 emoji 打头，要人行动用 👇；品牌或用户说不要才用纯文字。朋友圈写出人货场。文案示范补了一个几十字的短通知，并把“不必逐句加符号”这类说法改掉。

## 怎么跑的

- 三组：`v181`（沿用第一轮回答）、`cur`（已提交的 `63e6e3b`，快照 `bb17be86…`）、`fmt`（本轮改动，快照 `f54559f5…`）。
- 第一次跑时 `cur` 和 `fmt` 两组同时答题、共用一个临时目录，前 6 题答案互相覆盖，一字不差，整轮作废。重跑时两组各用自己的目录；`tools/ab_eval.py blind` 也加了检查，再出现一字不差的答案会直接拒绝。
- 打乱种子 20261024。两个全新评审（评审 9、评审 10）。
- **评审标准比前三轮多了两条**：结构清楚、好读算加分，大段文字扣分；给顾客看的文案没有 emoji、平淡不抓眼要扣分。这两条来自马甲本人的偏好，也正是本轮改动的方向，所以这轮的分数和前三轮不能直接比。
