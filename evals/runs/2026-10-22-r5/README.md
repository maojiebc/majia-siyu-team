# 2026-10-22 第五轮：先问立场和任务边界

## 改了什么（相对已提交的 v2.0.0，`a0b9c9b`）

来自一位茶饮连锁会员运营的真实反馈：领到的任务是把店庆拉新里没消费的九成转化回来，专家团第一句就让人放弃九成，纠正五六轮拉不回来，方案还把活动本身批了一遍，没法拿去汇报。

- 入口、问诊、团长编排、四官、任务接力都加了一步：先弄清对面是拍板的人还是领了任务的人。拍板的人，照马甲的判断全盘取舍；领了任务的人，任务就是边界，在任务人群里分层、先试一小批，马甲会怎么取舍另起一段“给你自己看”，说一次。方案要交给领导看的，不替用户批已经做完的活动。细则在 `knowledge/00-methodology/经营画像与执行边界.md`。
- 入口为了塞下这一段压了几句话，意思没变。
- 题库加一道 `assigned_task_unconverted`，照这条反馈改写（品牌、数字都换了）。

快照：现版 `dd5a2a46…`，新版 `e0ca5cf9…`（都是 `skillhub/majia-siyu` 发布包）。

## 怎么跑的

- 三组：`bare`（不装技能，前 14 题沿用第一轮回答，新题新答）、`cur`（已提交的 v2.0.0，本轮重新作答）、`new`（本轮改动）。`cur` 和 `new` 同一个模型、同一天答，每组拆成两个子代理，各用自己的工作目录。
- 打乱种子 20261025。两个全新评审（评审 11、评审 12），不同模型，评审标准和第四轮一样（好读加分、文案没 emoji 扣分、不因人名加减分）。新题的 `evidence` 写明了评审要看什么：有没有接住任务在九成里分层做，交给领导的方案里有没有批活动。

## 怎么读

- **新版和现版打平。** 老 14 题上两边互有胜负，评审给的理由都是和这次改动无关的细节（谁多了一招、谁篇幅紧）。
- **新加的那道题，两个评审都选新版，5 分对 4 分。** 理由一致：新版第一句接住任务，在九成里分四层、每层一句不同的话、小批试加留组不发，把“别写九成都转回来”“下次领券就让选店”放进“给你自己看”；现版虽然也分层、也不批活动，但第一句就是“别把目标写成九成”，开口就顶了领导派的任务。不装技能的那份第一句就说“相当一部分本来就转化不了”，还编了门店数、到期日和回流比例。
- 新版被记的严重错误：秒杀题里把不知道的券规则当成挤的原因写死（和改动无关）；新题里“归属只有两成，说明领券时没让选门店”把猜测写成了判断，这一条和“给你自己看”这段有关。
- 现版重新作答后，分数比第四轮的同版本低一点（4.73 / 4.53 对 4.57 / 4.79）。换了评审，不能直接比。

## 之后改了什么

- “给你自己看”那段补了一句：有依据的才写成判断，猜的就写明是猜的。（没有再测）
