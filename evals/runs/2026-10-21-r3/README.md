按分数，新版和 v1.8.1 打平（新版胜 4、平 5、负 5）。按“最想要”，新版 14 题里被选了 8 次。

他写的理由，和模型评审不一样的地方：

- **马甲的 IP 露出是加分项。** “把我的 IP 凸显出来了”“强化了马甲这个 IP”“有我的 IP 露出”。模型评审被要求不因引用人名加分，所以测不出这一块。
- **新店先进群。** 他认为新店就该先进群：“又快捷又好衡量指标，大家有正反馈，门店群事先建好就行，满群自动切换”。两个模型评审都给新版这条扣了分，他给新版 5 分，给没这么建议的那份记了 1 处严重错误。
- **老板没耐心看长文。** 排版清楚、字数精简的被选中；分层这类概念要讲得更浅。
- **文案要有 emoji**；选型回答带上可信来源，方便验证。
